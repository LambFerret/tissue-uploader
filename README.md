# 조직이식결과서 업로드

로그인 없이 의료기관명으로 사진을 업로드하는 웹앱입니다. 운영 구성은 **Workers + 비공개 R2 + D1**이며 데스크톱·안드로이드 Chrome을 지원합니다. 기존 Node 서버와 데이터도 보존했습니다.

## Cloudflare 로컬 실행

Node.js 24 이상.

```powershell
npm install
npm run cf:prepare
npm run cf:dev
```

업로드: http://localhost:8787 · 관리자: http://localhost:8787/admin

로컬 관리자 비밀번호는 `.dev.vars`의 `ADMIN_PASSWORD`입니다. 최초 준비 시 기존 `data/admin-password.txt`가 있으면 재사용하고 없으면 무작위 생성합니다. 로컬 R2·D1은 `.wrangler/`에 에뮬레이션되며 실제 Cloudflare에 사진을 전송하지 않습니다. 기존 Node 사진은 자동 이동하지 않습니다.

실제 배포와 통계 권한 연결은 [DEPLOY_CLOUDFLARE.md](DEPLOY_CLOUDFLARE.md)를 참고하세요.

## 기능

- 공개 화면 제목: `조직이식결과서를 업로드해주세요.`. 의료기관명과 기능 버튼만 표시합니다.
- 의료기관명·익명 방문자 ID는 localStorage에 유지합니다. 기관 인증 수단은 아닙니다. 기기 변경·저장소 삭제·시크릿 모드에서는 새 이용자입니다.
- 다중 선택, 드래그 앤 드롭, 모바일 촬영, 진행률, 실패 항목 재시도. 30장을 선택해도 최대 3장씩 전송합니다.
- 원본 그대로 보관. 썸네일과 ZIP용 CRC는 브라우저에서 생성하고 Worker는 R2로 스트리밍합니다. JPG·PNG·WebP·GIF·AVIF, 장당 30MiB, 1억 화소 이하. 브라우저가 해당 사진을 읽을 수 있어야 합니다. HEIC·RAW는 JPG로 변환하세요.
- 참여자는 같은 브라우저에서 올린 사진만 조회·다운로드합니다. 관리자만 전체 사진에 접근합니다. 비공개 R2를 사용합니다.
- 관리자 `/admin`: 비밀번호, 24시간 HttpOnly 세션, 로그인 시도 제한, 기관명 부분 검색, 업로드 시작일~종료일(KST, 종료일 포함), 최신·오래된·기관명 가나다·역순. 페이지당 60장.
- 상단 파일 수·기관 수·원본 용량은 필터와 무관한 전체 값입니다. **자동 갱신은 껐으며 ‘새로고침’을 누를 때만 갱신**합니다. 적용된 필터·페이지·남아 있는 선택은 유지합니다. 입력 중인 검색어는 ‘조회’를 눌러 적용합니다.
- 선택/전체 ZIP 다운로드. Cloudflare는 100장씩 분할하고 모든 페이지의 조회 결과를 포함합니다. 각 분할을 눌러 다운로드합니다. 서버 압축·원본 전체 메모리 버퍼링은 하지 않습니다.
- 링크·QR 공유, Android 홈 화면 바로가기용 매니페스트. 오프라인 업로드는 지원하지 않습니다.

## 관리자 무료 한도 통계

| 항목 | 기본 무료 기준 | 범위 |
|---|---:|---|
| R2 원본 + 썸네일 | 현재 10GB 참고선 | 이 앱, 9.5GB부터 빨간색 |
| Workers 요청 | 10만 회/일 | 계정 전체 |
| R2 Class A 쓰기·목록 | 100만 회/청구 주기 | 계정 전체 |
| R2 Class B 읽기 | 1,000만 회/청구 주기 | 계정 전체 |
| D1 읽은 행 | 500만 행/일 | 계정 전체 |
| D1 쓴 행 | 10만 행/일 | 계정 전체 |
| D1 저장량 | 5GB | 계정 전체 |

사용량·한도·남은 양·비율·집계 시각을 표시하고 95%부터 빨간 경고를 표시합니다. 토큰이 없으면 `미연결`, 권한/API 오류는 `조회 실패`, 오래된 값은 `갱신 지연`입니다. 이전 일일·월간 주기의 값을 현재 사용량으로 표시하지 않습니다. R2 청구 주기가 없으면 `청구 주기 미설정`입니다.

Cloudflare 요청 통계는 Cron으로 15분마다 수집하고 화면에서는 ‘새로고침’으로 읽습니다. 사진 전체 통계는 D1 트리거로 유지하고 목록 검색은 변경 버전별로 5분간 재사용합니다. 새 검색 조건을 적용할 때는 해당 검색을 실행합니다.

Workers Free·D1 Free·R2 Standard 기준 참고선이며 청구액 계산기나 자동 과금 차단 기능은 아닙니다. 계정 요청 집계는 지연·샘플링으로 청구 수치와 다를 수 있습니다. R2 저장 요금은 GB-month 기준입니다. 앱 저장량은 전용 버킷에 이 앱이 저장한 원본·썸네일 및 미완료 업로드의 저장 영수증 합계입니다. 외부에서 넣은 객체·다른 버킷·별도 백업은 포함하지 않습니다.

## 기존 Node 실행

`npm start` → http://localhost:3000, 관리자 `/admin`. 비밀번호는 `.env`의 `ADMIN_PASSWORD` 또는 `data/admin-password.txt`. 사진·SQLite는 `data/`에 있습니다. 종료 후 `data/` 전체를 백업합니다. 기존 Docker·EC2 설정은 Node 버전용입니다. Node 버전에는 Cloudflare 통계를 표시하지 않습니다.

## 검증

```powershell
npx playwright install chromium
npm run cf:check
npm run test:cloudflare
npm test
```

Cloudflare 테스트는 실제 workerd의 로컬 D1·R2에서 실행합니다. 약 2MB JPG 30장, 원본 SHA-256, ZIP CRC/추출 결과, 접근 통제, 관리자 로그인, 필터·전체 통계, 수동 갱신, 5만 건 합성 메타데이터 조회, 경고 경계·주기 변경을 검사합니다. 과금 지표 경계 검사는 모의 데이터이며 실제 Analytics 연결 검증과 다릅니다. 95GB 실물 원본·안드로이드 실기기·운영 CPU 제한 부하 테스트는 아닙니다.
